# 🎯 Wordle Game

A browser-based Wordle clone where players try to guess a five-letter word within six attempts. Visual feedback helps the player get closer to the answer with every guess.

## 🌐 Live Demo

🔗 [Play the game here](https://pradipta762.github.io/Wordle-Game/)

## 🛠 Tech Stack

- HTML  
- CSS  
- JavaScript

## 🎮 How to Play

- Guess the five-letter word in six tries.
- After each guess:
  - ✅ Correct letter & position → **Green cell with white text**
  - 🟡 Correct letter, wrong position → **Yellow cell with black text**
  - ⬛ Letter not in the word → **Gray cell with white text**
